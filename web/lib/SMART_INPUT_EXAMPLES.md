# Smart input examples

Supported optional shortcuts for task titles:

- `Matematika v 17:30 na 60 minut`
- `Matika 17:30 45 min`
- `CFI zítra od 16 na hodinu`
- `Angličtina od 18 do 19:30`
- `Ekonomie dnes do 18:00 důležité`

All fields remain optional. Manual controls take precedence over hints written in the title.
